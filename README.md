A napari plugin for loading, visualizing, and editing centerlines generated by **WormTracer**, frame-by-frame, and saving the refined results. This tool is designed for workflows where manual refinement of centerlines or skeleton paths is needed across time-lapse or multi-frame data.



## Data Formats

* **Mask/Image File**: Typically a binary or grayscale mask (.tif, .avi, ...etc).
* **Centerline File**: A `.csv` file containing the centerline coordinates exported from **WormTracer**. (ex:  `sample_1_x.csv` and `sample_1_y.csv` in the same folder) or a `.hdf` file containing two datasets, namly "x" and "y", respectively.


## Usage

| Button                 | Description                                                                                   |
| -------------------    | --------------------------------------------------------------------------------------------- |
| **Load Image**         | Load images into napari (*.tiff, and *.mp4, same as `File > Open File(s)`) #1                 |
| **Load Centerline**    | Load an existing centerline or set of centerlines.                                            |
| **Resume Status**      | Resume the plugin status from pickle file (.pkl, pickle)                                      |
| [**Save Status**](#saving-and-resuming-state)        | Save current status (ex: centerline path and modify history) as pickle file                   |
| **Refetch Centerline** | Refetch the centerline from the file and clear all modified history                           |
| **Flip Head/Tail**     | Flip the head and tail orientation.                                                           |
| **Reset Centerline**   | Discard all unregistered changes and step back to lastest changes                             |
| **Register**           | Apply registration to the current frame.                                                      |
| **Undo Modify**        | Undo the last edit, such as flip, register, and mark as guide.                                |
| [**Mark as Guide**](#mark-as-guide)      | Labeling all frames (from-to) as guide(modified).                                             |
| **Export Centerline**  | Save all edited centerlines to a new file, named with 8-digit barcode.                        |
| [**Export As**](#export-as)          | Output format (HDF or CSV). If `with guide` was checked, the guide files will also be exported|
| **Apparent**           | Display Preferences setting, such as color, label size and body thickness                     |
                            
### Workflow
1. Open napari.
2. Open the plugin from the napari plugin menu.
3. Use **Load Image** to open your image data. 
   > To load tiff/png/jpeg sequence, use `File > Open Files as Stack...` or `File > Open Folder`.
4. Use **Load Centerline** to load centerline coordinates.
   > Plugin only supports 2 CSV files or 1 HDF file. 
   > - Two CSV files: the two files need to named as following: `zzzzzzz_x.csv` and `zzzzzzz_y.csv`. When csv file (either `_x` or `_y`) was selected, the plugin will search the corresponding csv file from the same folder and assign it as opposite axis (`y` or `x`).  
   > - HDF file: HDF file must contain two datasets, namly `x` and `y`.
5. Select the body layer (`centerline`) to modify the centerline via dragging the existed points or using freehand drawing.
6. You can use verdices tools directly modifying the points directly, or drawing a new line via tools, such as `Add lines` or `Add Path`. The register will create a new centerline based on your drawing.
7. After finished the modification at 6, press the register. Then, the plugin will automatically generate interploated centerline based on your modification. And the label will mark as Guide(+1). Increment number represent how many time this frame was modified.
8. Use **Export Centerline** to save the revised centerlines, once all frames are reviewed and corrected.

### Saving and Resuming State
To save the plugin's state and your change history, use the `Save Status` button to save the current history and frame number; you can later resume your previous work using `Resume Status` to load the status from the pickle file .

### Mark as Guide
- `From/To`: The range of frame to be marked as guide (inclusively). 
- `Label`: pressed to marked the selected range as guide. 

### Export As 
The output format can be specified in the `Export As` block. 
- `.csv` or `.h5`: The file can be saved as two separate csv files (`zzzzzz_x.csv`, and `zzzzzz_y.csv`) or one HDF5 file (`zzzzzz_x.h5`), contains two dataset `x`, and `y`. All output files will suffix with 8-digit barcode to avoid overwrite.
- `plot_n`: sepecify the number of points on the centerline to save, default will be set the same as input size after loading the centerline.
- `with_guide`: If `with guide` was checked, the napari-wormtracer will stimutanously save an additional files suffixed with `_guide`, in which only the modified or marked frames will be saved as usual, and other frames will be saved as `nan`. The guide file can be used as reference input for wormtracer to rerun the analysis.

## Requirements

* numpy
* scipy
* h5py
* napari 
* magicgui
* qtpy
* imageio[ffmpeg] # optional, used to load MP4 files.

## Installation

You can install `napari-wormtracer` via [pip]:

```
pip install napari-wormtracer
```

If napari is not already installed, you can install `napari-wormtracer` with napari and PyQt6 via:

```
pip install "napari-wormtracer[all]"
```
